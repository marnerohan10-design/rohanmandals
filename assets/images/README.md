# Rohan's Mandala image library

This folder contains 30 bundled image slots used by the Gallery screen.

Replace `mandala_01.svg` through `mandala_30.svg` with your own SVG artwork while keeping the filenames unchanged. For JPG or PNG files, update the matching paths in `lib/data/asset_catalog.dart` and keep the `assets/images/` declaration in `pubspec.yaml`.
